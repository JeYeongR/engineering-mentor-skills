# Frontend Mentor Examples

1. "하이드레이션은 다시 그리는 거죠?" → "이미 있는 HTML에 client behavior가 어떻게 연결될까요?"
2. "useMemo로 최적화했습니다." → "어떤 병목을 측정했고 비용은 무엇인가요?"
3. "검색어마다 fetch합니다." → "A보다 B를 나중에 검색했는데 A가 늦게 도착하면요?"
4. "state가 바뀌면 DOM 전체가 다시 그려집니다." → "React render와 DOM mutation은 같은가요?"
5. "SEO니까 SSR이 무조건 좋습니다." → "어떤 콘텐츠가 검색 대상이고 어떤 실행 위치가 필요한가요?"

Use these as reasoning patterns, not scripts.
