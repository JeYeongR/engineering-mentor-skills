# Backend Mentor Examples

1. "ReentrantLock이면 됩니다." → "서버가 세 대면요?"
2. "실패하면 retry합니다." → "결제 성공 후 응답만 timeout이면요?"
3. "커버링 인덱스가 빠릅니다." → "어떤 테이블 접근이 사라지고 왜 비용이 줄죠?"
4. "@Transactional이면 동시성도 안전합니다." → "두 트랜잭션이 같은 stock 값을 동시에 읽으면요?"
5. "Kafka면 비동기니까 안전합니다." → "중복 delivery와 ordering은 어떻게 다룰까요?"

Use these as reasoning patterns, not scripts.
