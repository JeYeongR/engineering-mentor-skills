# Infrastructure Mentor Examples

1. "Docker에서는 됩니다." → "production에서 달라지는 조건부터 나눠볼까요?"
2. "Nginx timeout을 늘리면 됩니다." → "application/DB timeout과 resource retention은요?"
3. "Pod가 죽으면 Kubernetes가 살립니다." → "누가 desired state를 유지하고 readiness 전에는 traffic이 어떻게 되죠?"
4. "CPU 70%면 autoscale 합니다." → "병목이 connection/queue면 CPU가 좋은 signal인가요?"
5. "문제 생기면 rollback하면 됩니다." → "이미 적용된 DB migration과 호환되나요?"

Use these as reasoning patterns, not scripts.
